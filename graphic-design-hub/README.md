GraphicDesignHUB

About the Project

GraphicDesignHUB is a web-based learning platform created for students who want to improve their graphic design skills. The website provides a simple login page and an interactive dashboard with useful design-related information and resources.

Main Features:
*User login and logout functionality
*Interactive dashboard
*Collapsible sidebar navigation
*Design class popularity statistics
*Design academy enrollment statistics
*Software and asset usage information
*Design Skills Index chart
*Search bar
*Interactive buttons and navigation effects
*Responsive and modern user interface

Technologies Used:
HTML5 – Website structure
CSS3 – Design, layout, and styling
JavaScript – Interactivity and functionality
Font Awesome – Icons
SVG – Dashboard charts

Project Structure:
GraphicDesignHUB/
├── index.html
├── Project 2-1.css
├── Project 2 -1.js
├── 2c39a9d00e3512063a3916ae53c506d9.jpg
└── README.md

How to Run:
1.Download the project files.
2.Keep all files in the same folder.
3.Open index.html in a web browser.
4.Enter a username/email and password.
5.Click SIGN IN to view the dashboard.

No database or server is required for the current version.

Project Purpose:
The purpose of GraphicDesignHUB is to create a user-friendly platform where students can explore graphic design classes, academies, instructors, assignments, portfolios, and other design resources.

Future Improvements:
Future versions could include real user accounts, course enrollment, instructor profiles, student chat, assignment submission, database integration, and online design resources.
